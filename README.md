# Last Time Ivantey Scored

⚽ Шуточный Telegram-бот для нашего футбольного коммьюнити: считает, сколько времени прошло с последнего гола **Ивантея** (уже почти 2 года и всё ещё тикает).

Команда `/gol` → `последний раз Ивантей забивал 1 год 8 месяцев 18 дней и 42 секунды`

**Стек:** Node.js, Telegraf, Express (keep-alive)

```bash
# .env → BOT_TOKEN=...
npm install && node index.js
```

*Придуман в шутку — не production, а мем для друзей.*
